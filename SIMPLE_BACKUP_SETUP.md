# BASSE ONLINE SHOP — SIMPLE BACKUP VERSION

This version intentionally does not use GitHub, cloud backup, GitHub tokens, or cloud auto-restore.

It uses the existing BASSE local SQLite database and local full-backup file. The Admin Dashboard keeps:
- Automatic shop save
- SAVE SHOP NOW
- DOWNLOAD FULL BACKUP
- Restore backup

Full downloaded backups include database records and uploaded product images.
